# PHP standards

## Layout

- Put application code under `src/`, autoloaded by PSR-4 from the `Washgate\Invoicing\` namespace.
- Match every namespace segment to a folder and every class to a file of the same name.
- Split `src/` into folders named for a role (`Invoice/`, `Http/`) once a second role arrives. Do not create `Utils/`, `Helpers/`, or `Common/`.
- Keep one class, interface, or enum per file.
- Keep the web entry point to wiring. Put logic in classes under `src/`.

## Files and typing

- Open every file with `declare(strict_types=1);`.
- Type every parameter, return, and property. Do not use `mixed` outside a boundary that decodes outside input.
- Mark classes `final` unless one is designed for extension.
- Use `readonly` properties and constructor promotion for value objects.
- Use a backed `enum` for a closed set of values over class constants.
- Add `#[\Override]` to every method that overrides a parent or implements an interface.

## Errors

- Throw a specific exception class. Do not throw `\Exception` itself.
- Name the bad value and the expected shape in an exception message.
- Do not suppress errors with `@`.
- Catch only an exception you can handle, and rethrow with the original as `previous`.

## Database

- Use PDO with `PDO::ERRMODE_EXCEPTION` and prepared statements for every query.
- Apply `.claude/rules/canon/lib/370-database.md` to every query and transaction in PHP.
- Bind every runtime value. Never interpolate a value into SQL.
- Apply `.claude/rules/canon/lib/360-security-server.md` to every endpoint that takes outside input.

## Dates and money

- Use `DateTimeImmutable` with an explicit `Europe/Stockholm` time zone. Do not use `date()` or `strtotime()`.
- Store and compute money as integer öre. Do not use floats for amounts.

## Tooling

- Keep code passing PHP-CS-Fixer with `@PER-CS` and PHPStan at `level: max`.
- Run `bun run lint:fix`, `bun run typecheck`, and `bun run test:run` from `invoicing/` before committing.
- Do not add a `@phpstan-ignore` without a reason on the same line.
